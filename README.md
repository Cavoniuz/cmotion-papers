# C-motion papers

This repository contains the LaTeX source and compilation dependencies for a coordinated collection of six C-motion preprints by Toma Kavonius. Each paper states its own assumptions, limitations and scientific status; inclusion here does not imply that open questions have been resolved.

| Paper | Source directory | Zenodo record DOI |
| --- | --- | --- |
| Main Framework | [main](papers/main/) | [10.5281/zenodo.24481577](https://doi.org/10.5281/zenodo.24481577) |
| Quantum Foundations | [quantum](papers/quantum/) | [10.5281/zenodo.24481842](https://doi.org/10.5281/zenodo.24481842) |
| Structural Entanglement I | [singlet](papers/singlet/) | [10.5281/zenodo.24482061](https://doi.org/10.5281/zenodo.24482061) |
| Thermodynamics | [thermodynamics](papers/thermodynamics/) | [10.5281/zenodo.24482472](https://doi.org/10.5281/zenodo.24482472) |
| Gravity | [gravity](papers/gravity/) | [10.5281/zenodo.24482696](https://doi.org/10.5281/zenodo.24482696) |
| Standard Model Structure I | [standard-model-i](papers/standard-model-i/) | [10.5281/zenodo.24482849](https://doi.org/10.5281/zenodo.24482849) |

These record DOIs have been reserved for individual papers; links may not resolve until their records are published. No DOI has been assigned to the collection itself. For build commands, see the README in each paper directory. For citations, cite the individual paper; see [CITATION.cff](CITATION.cff) and [publication records](PUBLICATION_RECORDS.md).

The intended version 1.0 release would distribute the six validated PDFs and six corresponding source archives as release assets, separately from ordinary Git history. This is a plan, not a declaration that a GitHub release or Zenodo publication has occurred.

## Related projects

A future `Cavoniuz.github.io` site could link to the individual paper records and release assets. Existing interactive Study Edition readers and standalone plain-English PDFs are separate resources, not part of this repository. A later curated `cmotion-research` repository could hold selected supporting research, subject to its own review and publication decisions. None of these projects is implemented or automatically linked here.
